# Portfolio Boundaries

This project is intentionally separated from any employer environment.

## Excluded

- Corporate source code
- Corporate Power Platform exports
- SharePoint URLs
- Employee names or personal data
- Corporate email addresses
- Credentials, tokens or secrets
- Internal approval groups
- Production configuration
- Internal screenshots containing company information

## Included

- General architecture patterns
- Generic data model
- Generic workflow logic
- Generic validation rules
- Low-code engineering practices
- ALM concepts
- Documentation and technical reasoning

The repository is designed to demonstrate transferable engineering capability rather than reproduce a proprietary implementation.
